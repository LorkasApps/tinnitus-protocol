# Tinnitus Protocol

Local Android app (Flutter) for logging tinnitus symptoms throughout the day.

## Features

- Tinnitus entry: loudness, distress (each 1–10) + free-text notes — multiple times per day
- Sleep log: separate table, one entry per day (upsert by date), quality 1–10 + notes
- Trend charts: configurable period (7 / 30 / 90 days / all), per-entry or daily-average view
- Sleep chart (one point per day)
- Key figures table: min / mean / median / max for each metric
- Time-of-day heatmap (morning / midday / afternoon / evening / night) for tinnitus entries
- Export as CSV (two files) or JSON (single file) via system share sheet
- Material 3, dark mode follows system
- Localized: English (default) and German, picked from system locale
- Data stays on device only (SQLite via [Drift](https://pub.dev/packages/drift))

## Stack

Flutter 3 / Dart 3, Riverpod, Drift, fl_chart, share_plus, intl.

## Setup

```bash
./setup.sh
```

The script adds the Android platform files (`flutter create`), pulls dependencies,
runs the Drift code generator, then analyzes and tests.

Prerequisite:

```bash
brew install --cask flutter
flutter doctor
```

## Build & Run

```bash
flutter build apk --debug          # APK
flutter run                        # device / emulator
```

## Localization

Localized strings live in `lib/l10n/app_en.arb` (template) and `lib/l10n/app_de.arb`.
The Dart code is generated by `flutter pub get` (since `flutter.generate: true`).
To add a locale, drop a new `app_<lang>.arb` next to the existing ones and add it
to `supportedLocales` (handled automatically by the generator).
